# ТрекДек (синяя версия)

Телефон = стрим-панель (плитки-макросы, страницы) + трекпад для ПК. Работает по Wi‑Fi.

## 1. ПК (Windows 11)
1. Запусти `TrekDeck-PC.exe` (установка не нужна).
2. Разреши доступ в брандмауэре Windows для частных сетей (всплывёт при первом запуске).
3. В чёрном окне увидишь **PIN** и **адрес ПК**. Окно не закрывай (можно свернуть).
Настройки хранятся рядом с exe: `trekdeck-config.json`.

## 2. Телефон (Android)
1. Установи Android Studio, открой папку `android/`, дождись синхронизации Gradle.
2. Подключи телефон (отладка по USB) → Run, или Build → Build APK(s) и установи APK.
3. Телефон и ПК — в одной Wi‑Fi сети. ПК найдётся сам; введи PIN.

## Получить APK без Android Studio (через GitHub)
1. Создай на github.com новый репозиторий (можно приватный) и загрузи в него **всё содержимое** папки (Add file → Upload files), включая скрытую папку `.github`.
2. Открой вкладку **Actions** → «Build APK» → **Run workflow**. Через 3–5 минут сборка завершится.
3. Открой завершённый запуск → внизу **Artifacts → TrekDeck-apk** → скачай, распакуй, перекинь `.apk` на телефон и установи (разреши «установку из неизвестных источников»).

## Управление
- Тап по плитке — выполняется макрос на ПК.
- «✎ Правка» или долгое нажатие на плитку — изменить иконку, название, цвет, команды.
- Долгое нажатие на вкладку — переименовать / удалить страницу; «＋» — новая.
- Касание **пятью пальцами** — переключение «панель ⇄ трекпад».
- Трекпад: 1 палец — курсор, тап — клик, 2 пальца — прокрутка, тап двумя — ПКМ, тремя — СКМ.

## Команды макросов (по одной в строке)
    key ctrl+shift+m        сочетание клавиш
    type Привет!            напечатать текст
    open https://...        открыть сайт / файл / папку
    start notepad.exe       запустить программу
    media playpause         playpause | next | prev | stop | volup | voldown | mute
    wait 500                пауза, мс

## Пересборка ПК-части
    cd pc
    GOOS=windows GOARCH=amd64 go build -ldflags "-s -w" -o ../TrekDeck-PC.exe .
